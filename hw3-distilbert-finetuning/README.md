# HW3 — Transformer Fine-Tuning & Lexical Semantics

- `run_distillbert.py` (+ `_i1`/`_i2`/`_i3`/`_j` variants for different runs/settings) —
  fine-tunes DistilBERT for sentiment classification on the same movie-review corpus as HW2, to
  compare a fine-tuned transformer against the classical baselines.
- `run_wordnet.py` — explores WordNet lexical relations via NLTK: synsets, definitions,
  hypernyms, and semantic similarity between word pairs.
